# 8BitNewsES — метаданные публикаций

Что ставим при публикации: заголовок, описание, теги, хэштеги, настройки. Язык — es-ES.

- **Script** пишет редакционную часть под каждую площадку: заголовок, суть, хэштеги, теги YouTube.
- **hub** собирает итоговое описание по шаблонам ниже. Он добавляет блок источников, ссылку на страницу источников,
  раскрытие AI и строку об исправлениях. Модель эти блоки не пишет.
- **Лимиты и поля API** площадок — в `platforms/<platform>/rules.md`. Правила об источниках — в `countries/es/policy.md`.
- **Публикация без подтверждения** (`moderation.approval_required: false`, решение владельца 09.11.2026,
  `docs/automation.md`). Карточка уходит в группу модерации для сведения, релиз одобряется сам и попадает в очередь
  загрузки на те площадки, которые допустил Legal. Ролик встаёт в расписание на ближайший свободный слот канала; когда он
  вышел, hub видит это сам и отмечает «🟢». «🚫 Закрыть страницу источников» закрывает релиз; ролик, уже стоящий в расписании, на подключённом канале hub снимает сам, а иначе его надо снять в Studio; «↩️ Не выложено» убирает
  его из списка канала; «📦 Пакет ещё раз» присылает пакет. Шаблоны описаний hub берёт из блоков кода ниже, настройки —
  из списков «Настройки». В TikTok на собственные аккаунты правила аудита автозагрузку не допускают
  (`docs/architecture.md` §14).

## Общие правила

**Заголовок**
- Говорит, что нового, — фактом, без оценки.
- Длина — до 70 символов, чтобы был виден целиком.
- Обвинения атрибутированы: «La Fiscalía dice…», «según…».
- Нельзя:
  - капслок, эмодзи, «ÚLTIMA HORA», «BOMBAZO», «no te lo vas a creer»;
  - вопрос-приманка и обещание того, чего нет в ролике;
  - имена частных лиц и несовершеннолетних.

**Суть** — 1–2 предложения: что нового и почему это важно. Только из `review.whats_new` и `review.known` досье.

**Хэштеги** — 3–5 штук:
- брендовый `#8BitNews` и 2–4 по сюжету: тема, место, учреждение или событие (`#Vivienda`, `#Madrid`, `#TribunalSupremo`);
- нельзя:
  - лозунги сторон и хэштеги кампаний;
  - оценочные хэштеги (`#Corrupción`, `#Escándalo`);
  - имена частных лиц;
  - трендовые теги не по сюжету: правила площадок считают их спамом.

**Теги YouTube** — 5–15 ключевых слов: люди и учреждения из сюжета, тема, место, `análisis de noticias`. Без тегов
чужих каналов и брендов.

**Упоминания.** Людей через @ не отмечаем, имена пишем текстом: в Instagram отметка героя критического ролика
повышает риск удаления за травлю.

**Призывы.** Никаких политических призывов («vota», «firma»). Нейтральный призыв канала — по формату
канала **[предложение]**: «Síguenos para más análisis».

## YouTube Shorts

```
{summary}

Qué hay de nuevo, qué se sabe y cómo se reparten las opiniones dentro y fuera de España.

Fuentes:
{sources_block}
Todas las fuentes y copias archivadas: {sources_page_url}

Aviso sobre IA: guion escrito con IA, narración sintética e imágenes de pixel art generadas con IA; las personas reales aparecen de forma estilizada.
Correcciones: {corrections_contact}

{hashtags}
```

**`sources_block`** — до 8 строк вида `• {outlet}{marks}: {title} ({date}) {url}`:
- сначала первоисточники, затем источники с наибольшим числом фактов ролика;
- `{marks}`: ` (de pago)`, ` (medio estatal)`.

**Настройки:**
- категория News & Politics;
- «made for kids» — нет;
- метка синтетического или изменённого контента — да: в YouTube Studio это вопрос «Altered content», в API —
  `containsSyntheticMedia=true` (по `policy.md`);
- обложка — `cover.png` из `video_package`: иначе YouTube сам выберет кадр, часто без темы ролика;
- видимость — Private с расписанием на слот канала: в Studio «Schedule», в API `status.privacyStatus=private`
  и `status.publishAt`; постоянное согласие на это даётся на `/admin/youtube`;
- язык метаданных и звука — Spanish (Spain);
- комментарии включены;
- плейлист по сюжетной линии для долгих сюжетов **[предложение]**.

## TikTok

```
{title}
{summary}
Fuentes: {sources_page_short}
Guion, voz e imágenes con IA.
{hashtags}
```

В подписи нет «(enlace en el perfil)»: ссылка в профиле TikTok появляется только с 1 000 подписчиков
(`platforms/tiktok/rules.md`); когда появится — вернём.

**Настройки:**
- метка «AI-generated content» — да (при публикации — в «More options»);
- обложка — кадр с заголовком (`video_cover_timestamp_ms`), а не первый кадр по умолчанию;
- комментарии включены;
- Duet и Stitch выключены **[предложение]**: новостной ролик легко вырвать из контекста;
- видимость — публично; через API до аудита приложения TikTok — только приватно.

## Instagram Reels

```
{title}
{summary}
Fuentes: {sources_page_short} (enlace en el perfil)
Guion, voz e imágenes con IA; las personas reales aparecen como ilustraciones estilizadas.
{hashtags}
```

**Настройки:**
- показывать в ленте — да;
- обложка — `cover.png` из `video_package` (бот присылает её файлом);
- AI-метка — да: в приложении «Advanced settings» → «Add AI label», в API — `is_ai_generated=true`. Синтетический
  голос Instagram прямо относит к обязательной маркировке.

## Страница источников

Одна страница на ролик, плюс индекс канала для ссылки в профиле. Обе hub отдаёт без ключа API:
- ролик — `{HUB_PUBLIC_URL}/s/{код}`, код — первые 10 шестнадцатеричных знаков id релиза. Открыта с момента одобрения:
  на неё ссылается описание, поэтому она должна работать, как только ролик выйдет;
- индекс канала — `{HUB_PUBLIC_URL}/c/{id канала}`. В нём ролики, которые hub увидел на площадке, или те, где модератор нажал «🟢 Выложено на площадки».

На странице:
- заголовок, дата и суть ролика;
- что говорит ролик, сцена за сценой, и источники каждой сцены: издание, заголовок, дата, ссылка, архивная копия,
  пометки paywall и state media. Только источники, которые hub проверил при сдаче релиза; те, что ни одна сцена
  не называет отдельно, — в конце списком. Если при проверке страница источника не открылась (404, «не найдено»,
  недоступный сайт), ссылка ведёт на архивную копию;
- коротко о том, как мы работаем (досье, группы мнений, AI-раскрытие);
- контакт и журнал исправлений. Журнал пока пустой: запись исправлений — следующим шагом.

Страница и список каналов — на испанском: hub берёт язык из `language` канала.

Пометки: `(de pago)` — у изданий с `paywall: true` в `countries/<cc>/sources.yaml`, `(medio estatal)` — у изданий
с `ownership: state_funded` или `state_controlled`.
