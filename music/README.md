# music — каталог фоновой музыки

Источник правды о треках, которые можно подкладывать под ролики (`docs/architecture.md` §5, «Музыка»).
Аудио и доказательства лицензий лежат в S3, здесь — метаданные. hub синхронизирует каталог в таблицу `music_tracks`
и выдаёт треки через `music_pick` только со статусом `approved`.

## Откуда треки

**[решено]** Пул треков, собранный заранее; каждый трек прослушивает человек. Генерации под каждый ролик нет.

**Источник** **[решено, 24.10.2026]** — бесплатный каталог: чиптюн под CC0 с OpenGameArt.org. CC0 разрешает
коммерческое использование без указания автора на любых площадках. API у каталога нет и не нужен: пул собирается
один раз, кандидаты — в `candidates.yaml`. Риски CC0:
- лицензию ставит сам загрузивший — каверы чужих мелодий и треки, загруженные не автором, исключаем;
- тот же трек могут использовать другие каналы, а кто-то может недобросовестно зарегистрировать его в Content ID.
  От такого claim защищают снимок страницы с лицензией и архивная копия в Wayback Machine.

Если хороших CC0-треков не хватит, добираем генерацией — Stable Audio 3 ($0,08 за генерацию, без подписки,
https://docs.stability.ai/pricing.md) или ElevenLabs Music. Что важно в Music Terms ElevenLabs
(ред. 09.10.2026, https://elevenlabs.io/music-terms):
- коммерческое использование онлайн разрешено на платных тарифах; исключены кино, ТВ, радио и игры;
  атрибуция не нужна начиная со Starter;
- права на трек — по тарифу, на котором он сгенерирован, даже после отмены подписки (§1.5);
- нельзя собирать из треков музыкальную библиотеку для третьих лиц (§4.2); каталог — только для наших каналов;
- тарифы до Pro — «For Individual Use Only»; организации до 10 сотрудников нужен Scale;
- раскрывать AI-музыку по правилам площадки обязан пользователь (§4.4).

Индемнификации нет: если на трек придёт претензия, защищаемся сами. Права на чисто AI-трек может не быть вовсе,
поэтому зарегистрировать треки в Content ID нельзя, и от ложных claims защищает только архив доказательств.

1. `briefs.yaml` — задания на генерацию: настроение, энергия, темп, стиль и промпт.
2. Генерация — по 2 варианта на задание с запасом на отбор. Каждый результат попадает в каталог со статусом
   `candidate` вместе с квитанцией генерации.
3. Прослушивание — человек ставит `approved` или `rejected` и отмечает, не напоминает ли трек известную мелодию.
4. Инцидент на площадке (claim, заглушённый звук) — трек получает статус `disabled`, причина пишется в `review.notes`.

## Формат `catalog.yaml`

```yaml
tracks:
  - id: chip-tense-01            # <стиль>-<настроение>-<номер>
    status: approved             # candidate | approved | rejected | disabled
    origin:
      kind: free_library         # free_library | generated | purchased | commissioned
      provider: tbd              # сервис генерации
      plan: tbd                  # тариф на момент генерации: от него зависит коммерческая лицензия
      terms_url: https://…       # условия сервиса
      terms_version: 2026-10-01  # редакция условий на момент генерации
      generation_id: …           # ID генерации у сервиса
      prompt: "…"
      generated_at: 2026-10-25T10:00:00Z
      receipt: licenses/chip-tense-01/       # каталог в S3 с доказательствами, см. ниже
    license:
      commercial: true
      platforms: [youtube, tiktok, instagram]
      attribution: null          # текст, если сервис требует атрибуцию в описании
      content_id: none           # none | unknown | registered_whitelisted | registered (CC0 из каталога — unknown)
    audio:
      key: music/tracks/chip-tense-01.wav    # ключ в S3
      sha256: …
      duration_s: 92
      bpm: 120
      loopable: true
    tags:
      mood: [tense]              # см. ниже
      energy: 3                  # 1 (фон) … 5 (драйв)
    review:
      listened_at: 2026-10-25
      notes: ""
```

В `receipt` трека из бесплатного каталога хранится:
- HTML страницы трека с лицензией и ссылка на её копию в web.archive.org;
- URL файла, дата скачивания, `sha256`;
- запись о прослушивании: кто, когда, решение.

В `receipt` сгенерированного трека хранится:
- полный JSON запроса (модель, промпт, план секций, seed, длина) и заголовки ответа с ID генерации;
- время генерации (UTC), аккаунт и тариф;
- счёт за месяц генерации;
- снимок условий сервиса в PDF и ссылка на копию в web.archive.org — одна на пачку треков;
- запись о прослушивании: кто, когда, решение.

Настроения: `neutral` — нейтральный фон под объяснение, `tense` — напряжение, конфликт, `urgent` — срочная новость,
`somber` — мрачный эмбиент для трагедий (тихо, без ритма), `hopeful` — разрядка, хорошие новости,
`curious` — расследование, загадка.

Схему каталога и её проверку в `cmd/profiles validate` делает эпик E2.
